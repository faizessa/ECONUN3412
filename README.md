## 📂 Repository Structure & Key Files

### 1. `recitations/` (Slides & Notes)
Contains recitation presentation slides, notes, and handouts in the compiled PDF format.

### 2. `do-files/` (Stata Scripts)
Contains executable, well-commented Stata companion scripts (`.do` files) replicating everything demonstrated in recitation.

### 3. `output/` (Data & Generated Files)
Working directory for data files and Stata logs generated by the do-files.
